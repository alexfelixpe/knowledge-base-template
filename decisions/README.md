# Decisions

`DECISIONS.md` is the running log of decisions the team has aligned on: what
was decided, who was in it, and the source.

`open/` holds decision queue items that are not yet ruled. One file per
question, named by topic, with the owner who should rule. When one is ruled, it
moves into the log with its reasoning, and the open file is deleted in the same
commit.

`inbox/` holds unapproved drafts of candidate decisions. See
[inbox/README.md](inbox/README.md).

Same subject and substance: amend the entry. A different ruling: a new entry
plus "superseded by" on the old one. Never rewrite or delete old text.
