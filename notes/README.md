# Notes: knowledge that is not a decision

Small pieces of knowledge worth keeping: a fact about the data, a doc someone
found, how something actually works. One file per topic (`<topic-slug>.md`),
with dated entries and a source. A person approves each note in the session, and
it is committed to `main` with no PR. When a note matures into architecture,
someone promotes it to `architecture/` by PR.

A topic that needs several files gets its own folder, with a `README.md` as its
start page.
